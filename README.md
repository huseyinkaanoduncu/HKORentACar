# HKORentACar - Car Rental Management System 🚗

## 📖 About The Project
HKORentACar is a comprehensive car rental management system built with **ASP.NET Core**. It provides a robust backend architecture for managing vehicles, customers, and rental operations. The project is designed with a strong focus on clean code principles, scalability, and maintainability.

## 🏗️ Architecture & Technologies
This project is built using an N-Tier (Layered) Architecture to ensure separation of concerns. 

*   **Backend:** C#, ASP.NET Core
*   **Database:** MS SQL Server
*   **ORM:** Entity Framework Core
*   **Architecture:** Layered Architecture (Core, Data, Business, WebUI)
*   **Design Patterns:** Repository Pattern, Unit of Work, DTOs (Data Transfer Objects)

## ✨ Key Features
*   **Vehicle Management:** Add, update, delete, and categorize vehicles.
*   **Rental Operations:** Manage car rentals, return dates, and pricing logic.
*   **Customer Management:** Track customer details and rental history.
*   **Data Integrity:** Secure transaction management using Unit of Work.
